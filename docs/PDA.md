# EasyWMS PDA H5

PDA 是与 Web 管理端分离的 React 应用，单独安装依赖、构建和部署；默认开发地址为 `http://localhost:5174`，通过 REST API 与 Java 服务通信。采用窄屏优先、触控大按钮、底部导航和安全区留白，适配 Android 手持 PDA、手机、平板、桌面浏览器与 WebView。前端提供 Web App Manifest，可安装到支持该能力的设备主屏幕。

## 参考功能映射

参考 `workspace/code/srm/upgrade-pda` 的主菜单、任务队列和逐条扫码作业模式，H5 工作台提供以下入口：

| PDA 模块 | H5 作业 |
| --- | --- |
| 采购管理 | 采购收货、送货单收货、质检放行、库存上架、采购退货、条码比对 |
| 领料管理 | 领料拣配、退料入库、委外出库、委外退库 |
| 成品管理 | 生产入库、成品返线、成品领料 |
| 销售管理 | 销售拣配、销售退库、装车标签比对 |
| 库存管理 | 库存查询、库位转移、库存盘点、报废出库 |
| 客供料管理 | 客供料收货、发出和退回 |
| 盘点巡检 | 循环盘点、库房巡检 |

任务队列复用服务端单据状态，可按全部、待办和已完成筛选，并依据用户权限显示提交、审批、驳回和过账操作。质检页面显示检验记录，并为有 `quality:decide` 权限的账号提供放行、暂挂和不合格处置。盘点数量按实盘数提交；出库和调拨的库存校验仍由服务端执行。

## 扫码与设备适配

- PDA 内置扫描头或 USB 扫描枪按键盘输入（HID）方式工作；扫描框保持焦点，并建议配置回车后缀。
- 在支持 `BarcodeDetector` 且有 HTTPS 摄像头权限的浏览器中，可使用后置摄像头扫码。
- 不支持相机扫码的 iOS、旧版浏览器或企业 WebView 可使用外接扫描器或手工输入。
- 扫描清单支持增减数量、编辑物料编码、名称、批次和单位；可连续扫描同一物料累计数量。
- 浏览器相机权限和主屏幕安装能力取决于设备、浏览器和 HTTPS 部署环境。
- PDA 可使用独立域名根路径部署；与 Web 共用域名并放在 `/pda/` 时，构建使用 `VITE_BASE_PATH=/pda/ npm run build`。API 地址通过 `VITE_API_BASE_URL` 独立配置。

## API 对接

PDA 登录使用 `POST /api/v1/auth/login`，并复用 JWT 权限与租户上下文。库存查询使用 `GET /api/v1/inventory`；移动、收货、出库、盘点作业创建 `POST /api/v1/documents`，再按权限提交单据；质检登记和判定分别使用 `/api/v1/quality/inspections` 及其 decisions 接口。完整请求定义见 [API.md](API.md) 和 Swagger UI。

## 当前实现边界

当前 WMS 单据模型每张单据只有一个物料行，因此 PDA 多次扫描后按物料行逐张创建单据。条码比对和库房巡检的扫描清单暂存于当前页面会话；服务端尚无专用波次、包装/装车复核、条码拆分打印和离线任务同步接口。企业使用前应补齐多行单据、扫描流水、幂等提交、审计记录以及目标设备验证。
